Снятие и установка внутренней облицовочной панели двери задка

Снятие

1. С помощью пластиковой лопатки поддеть и снять верхнюю декоративную панель двери задка.

2. С помощью крестовой отвертки выкрутить винты крепления левой и правой декоративных панелей двери задка.

3. Снять левую и правую декоративные панели двери задка.

4. С помощью крестовой отвертки выкрутить крепежные винты с обеих сторон нижней декоративной панели двери задка.

5. С помощью крестовой отвертки выкрутить крепежные болты внутри ниши ручки двери задка

6. Снять облицовочную панель двери задка.

7. С помощью плоской отвертки поддеть выключатель электропривода двери задка, отсоединить электрический разъем выключателя электропривода двери задка. Снять нижнюю внутреннюю облицовочную панель двери задка.

Установка

Установка выполняется в порядке, обратном снятию.

Внимание

Фиксаторы облицовочной панели двери задка являются одноразовыми элементами, при установке необходимо заменить их новыми фиксаторами облицовочной панели двери задка.
