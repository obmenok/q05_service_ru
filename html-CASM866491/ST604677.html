Замена нижней внешней панели боковины

  1. Снять оригинальную деталь:

    Предупреждение

    Меры предосторожности =＞ см. Ремонтные работы кузова — Защита автомобиля / Меры безопасности.

    • PHEV: внешняя панель боковины (левая) с лючком зарядного гнезда;

    Внимание

    • Измерить размеры геометрии кузова для правки, проверить соединительные элементы на предмет Деформация;

    • Использовать телескопическую измерительную линейку в качестве измерительного инструмента.

    Снять оригинальную деталь:

    1. Выполнить резку по линии реза, указанной на рисунке, удалить обрезанные кромки;

      Внимание

      • Оператор может ориентироваться по поперечным сечениям ключевых зон для регулировки положения и глубины реза;

      • Не допускается повреждение внутренних усилителей.

      • PHEV: внешняя панель боковины (левая) с лючком зарядного гнезда;

    2. Удалить герметик в зоне сварки и в зоне завальцовки до обнажения сварочных точек;

    3. С помощью подходящего инструмента высверлить сварные точки ①, показанные на рисунке;

    4. С помощью зубила и молотка разъединить сварные точки ① и завальцовку внешней панели боковины ②, демонтировать нижнюю внешнюю панель боковины ③.

  2. Подготовка новой детали:

    1. Обрезать внешнюю панель боковины на верстаке, оставив поперечное сечение достаточной ширины для установки новой детали;

    2. Удалить антикоррозионное покрытие с кромок внешней панели боковины;

    3. Нанести грунтовочный состав для сварки в местах сварки внешней панели боковины.

  3. Сварка:

    1. Очистить зону работ от сварочного грата, удалить антикоррозионное покрытие в зоне соединения кузова;

    2. Нанести грунтовочный состав для сварки в зоне работ;

    3. Зафиксировать обрезанную деталь новой внешней панели боковины на кузове с помощью самофиксирующихся зажимов;

    4. Отрегулировать установочное положение;

    5. Установить нижнюю внешнюю панель боковины ① на автомобиль, зафиксировать самозажимными фиксаторами;

    6. Проверить состояние выравнивания и сварные швы по периметру кромок;

    7. Проверить, перекрывается ли компонент с кромкой автомобиля, a: примерно 50 mm;

    8. Подрезать кромки листового металла, удалить излишки для формирования идеального сварочного зазора;

    9. С помощью аппарата точечной сварки сварить зону ①, указанную на рисунке;

    10. Зачистить сварочную поверхность, удалить сварочный грат;

    11. Нанести антикоррозионный состав на новую зону сварки;

    12. С помощью сварочного аппарата MIG сварить зону ①, указанную на рисунке;

    13. Зачистить сварочную поверхность, удалить сварочный грат;

    14. Нанести антикоррозионный состав на новую зону сварки;

    15. С помощью сварочного аппарата MIG сварить шов ①, указанный на рисунке;

    16. Зачистить сварочную поверхность, удалить сварочный грат;

    17. Нанести антикоррозионный состав на новую зону сварки;

    18. С помощью молотка завальцевать кромку внешней панели боковины ① до прилегания к тыльной стороне внутренней панели, следить за тем, чтобы видимая поверхность внешней панели боковины не была деформирована;

    19. Нанести герметик на зону соединения кузова.
