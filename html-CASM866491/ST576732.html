Замена компонента заднего лонжерона

  1. Снятие:

    Предупреждение

    Меры предосторожности, см. Защита автомобиля.

    Описание

    • Измерить размеры геометрии кузова для правки, проверить соединительные элементы на предмет Деформация:

    • Использовать измерительные инструменты, такие как телескопическая измерительная линейка.

    Снять оригинальную деталь:

    Описание

    • Оператор может ориентироваться по поперечным сечениям ключевых зон для регулировки положения и глубины реза;

    • Не допускается повреждение внутренних усилителей;

    • С помощью шабера удалить слой ПВХ-герметика в зоне порога;

    • Выполнить резку по зонам, указанным на рисунке.

    1. Очистить зону сварки до появления точек сварки;

    2. С помощью аккумуляторной дрели высверлить обнаженные сварные точки ①;

    3. С помощью зубила и молотка разъединить сварные точки и снять внешнюю панель боковины;

    4. Очистить зону сварки до появления точек сварки;

    5. С помощью аккумуляторной дрели высверлить обнаженные сварные точки ①;

    6. С помощью зубила и молотка разъединить сварные точки и снять задний отрезок усилителя порога ②;

    7. Очистить зону сварки до обнажения сварочных точек;

    8. С помощью аккумуляторной дрели высверлить обнаженные сварные точки ①;

    9. С помощью зубила и молотка разъединить сварные точки, отделив компонент заднего лонжерона от заднего днища;

    10. Очистить зону сварки до появления точек сварки;

    11. С помощью подходящего инструмента высверлить обнаженные сварные точки ①;

    12. С помощью зубила и молотка разъединить сварные точки и снять компонент заднего лонжерона.

  2. Подготовка:

    1. Очистить зону работ от сварочного грата, удалить антикоррозионное покрытие в зоне соединения кузова;

    2. Нанести грунтовочный состав для сварки в зоне работ;

    3. Удалить антикоррозионное покрытие вокруг новой детали ①;

    4. Нанести грунтовочный состав для сварки на кромки листовой детали;

    5. Зафиксировать компонент заднего лонжерона на кузове с помощью самофиксирующихся зажимов;

    6. Отрегулировать установочное положение компонента;

    7. Нанести грунтовочный состав для сварки в зоне работ.

  3. Сварка:

    1. Установить новую деталь на кузов, зафиксировать самофиксирующимися зажимами;

    2. Выполнить сварку зоны соединения ① с помощью аппарата точечной сварки;

    3. Выровнять место сварки, удалить сварочный шлак;

    4. Нанести антикоррозионный состав на новую зону сварки;

    5. Нанести герметик на зону соединения кузова;

    6. В точках, указанных стрелками, с помощью сварочного аппарата MIG сварить зону соединения;

    7. Выполнить сварку зоны соединения ① с помощью аппарата точечной сварки;

    8. Выровнять место сварки, удалить сварочный шлак;

    9. Нанести антикоррозионный состав на новую зону сварки;

    10. Нанести герметик на зону соединения кузова;

    11. Установить переднюю соединительную пластину внешней панели чашки заднего колеса ② на кузов, зафиксировать самофиксирующимися зажимами;

    12. Выполнить сварку зоны соединения ① с помощью аппарата точечной сварки;

    13. Выровнять место сварки, удалить сварочный шлак;

    14. Нанести антикоррозионный состав на новую зону сварки;

    15. Нанести герметик на зону соединения кузова;

    16. Установить заднюю часть внешней панели боковины ① на автомобиль, зафиксировать самозажимными фиксаторами;

    17. Проверить, перекрывается ли компонент с кромкой автомобиля, a: примерно 50 mm;

    18. Подрезать кромки листового металла, удалить излишки для формирования идеального сварочного зазора;

    19. Проверить состояние выравнивания и сварные швы по периметру кромок;

    20. Выполнить сварку зоны соединения ① с помощью аппарата точечной сварки;

    21. Выровнять место сварки, удалить сварочный шлак;

    22. Нанести антикоррозионный состав на новую зону сварки;

    23. Нанести герметик на зону соединения кузова;

    24. Нанести финишную эмаль на внешнюю поверхность;

    25. С помощью сварки MIG сварить шов ①;

    26. Выровнять место сварки, удалить сварочный шлак;

    27. Нанести антикоррозионный состав на новую зону сварки;

    28. Нанести герметик на зону соединения кузова;

    29. Нанести финишную эмаль на внешнюю поверхность.
