Передняя соединительная тяга

Снятие

1. Снять колесо. Ссылка: Колеса и шины

2. Выполнить Подъем автомобиля.

3. Использовать специальный инструмент для фиксации изнутри и вращения снаружи для Снятие гайки a переднего стабилизатора, передней стойки и передней соединительной тяги.

Крутящий момент: (120 ± 10) N.m

Внимание

При Снятие использовать хлопчатобумажную ткань для защиты шарового шарнира во избежание повреждений. При Снятие гайки использовать Специальный инструмент для фиксации изнутри и вращения снаружи, зафиксировать палец шаровой опоры для Снятие, запрещается фиксировать инструмент со стороны пыльника или выполнять Снятие гайки без фиксации пальца шаровой опоры во избежание повреждения пыльника и шарового шарнира.

Установка

Установка выполняется в порядке, обратном снятию.

Внимание

При Установка гайки передней соединительной тяги использовать хлопчатобумажную ткань для защиты шарового шарнира во избежание повреждений, использовать Специальный инструмент для фиксации изнутри и вращения снаружи для фиксации пальца шаровой опоры передней соединительной тяги при Установка, запрещается фиксировать инструмент со стороны пыльника или выполнять Установка гайки без фиксации пальца шаровой опоры во избежание повреждения пыльника и шарового шарнира.
