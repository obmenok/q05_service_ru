Описание принципа работы системы

Описание системы:

Разблокировка по Bluetooth: при выключенном питании автомобиля (положение OFF) откройте приложение «Changan Qiyuan», подключитесь по Bluetooth и нажмите «Разблокировать»; замки дверей разблокируются, после успешной разблокировки фонари аварийной сигнализации мигнут один раз.

Блокировка по Bluetooth: при выключенном питании автомобиля (положение OFF) и закрытых четырех дверях и багажнике откройте приложение «Changan Qiyuan», подключитесь по Bluetooth и нажмите «Заблокировать»; замки дверей заблокируются, после успешной блокировки фонари аварийной сигнализации мигнут два раза.

Поиск автомобиля по Bluetooth: при выключенном питании автомобиля (положение OFF) откройте приложение «Changan Qiyuan», подключитесь по Bluetooth и нажмите «Поиск автомобиля»; функция поиска активируется, автомобиль подаст звуковой сигнал, а фонари аварийной сигнализации начнут мигать, указывая на расположение автомобиля.

Подъем и опускание стекол по Bluetooth: при выключенном питании автомобиля (положение OFF) откройте приложение «Changan Qiyuan», подключитесь по Bluetooth и нажмите «Поднять стекла» / «Опустить стекла»; стекла выполнят подъем / опускание.

Разблокировка PE по Bluetooth: при выключенном питании автомобиля (положение OFF) после успешного подключения по Bluetooth нажмите кнопку PE на ручке двери водителя для разблокировки автомобиля.

Запуск PS по Bluetooth: при выключенном питании автомобиля (положение OFF) после успешного подключения по Bluetooth и нахождении телефона в салоне нажмите педаль тормоза для перехода в режим готовности к движению.
