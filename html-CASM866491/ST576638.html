Снятие и установка петель капота

Снятие

  1. Демонтировать крыло ①, для демонтажа крыла см. Крыло;

  2. С помощью динамометрический ключ выкрутить крепежные болты петель, как показано на рисунке;

  3. Момент затяжки болтов: 23 ± 3 N.m;

  4. Извлечь петли капота.

Установка

Установка в основном выполняется в обратном порядке.
