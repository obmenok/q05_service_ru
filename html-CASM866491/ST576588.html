Снятие и установка облицовочной панели задней двери

Снятие

  1. С помощью пластиковой лопатки снять узел панели переключателей стеклоподъемников.

  2. С помощью плоской отвертки поддеть штекер жгута проводов панели переключателей.

  3. С помощью плоской отвертки поддеть крышку винта внутренней ручки открывания.

  4. С помощью плоской отвертки поддеть крышку винта.

  5. С помощью крестовой отвертки выкрутить крепежные винты (как показано на рис. 1, 2, 3)

  6. С помощью пластиковой лопатки извлечь декоративную накладку треугольного окна задней двери

  7. С помощью пластиковой лопатки поддеть и снять облицовочную панель задней двери.

  8. Извлечь фиксатор жгута проводов низкочастотной антенны, наконечник троса внутренней ручки, фиксатор жгута проводов высокочастотного динамика (при наличии в комплектации) (как показано на рис. 1, 2, 3)

  9. Снять облицовочную панель задней двери, расположение фиксаторов показано на рисунке.

Внимание

Фиксаторы облицовочной панели задней двери являются одноразовыми деталями, при установке необходимо заменить их новыми фиксаторами облицовочной панели задней двери

Установка

Установка выполняется в порядке, обратном снятию.
