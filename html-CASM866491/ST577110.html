Требования к калибровке

Условия, при которых требуется калибровка:

  1. Демонтаж/установка подрамника двигателя, рычагов подвески, передней стойки, переднего тормоза (поворотного кулака) и других компонентов подвески; требуется повторная калибровка сигналов, связанных с IMU (подробности см. в разделе метода калибровки контроллера подушек безопасности (контроллер подушек безопасности));

  2. Демонтаж/установка контроллера подушек безопасности, требуется повторная калибровка сигналов, связанных с IMU (подробности см. в разделе метода калибровки контроллера подушек безопасности (контроллер подушек безопасности));

  3. Демонтаж/установка рулевого механизма, рулевого колеса, компонентов рулевой опоры, требуется заново выполнить регулировку углов установки колес и откалибровать сигналы, связанные с центральным положением EPS (подробности см. в разделе метода калибровки центрального положения EPS);

  4. При замене компонентов интегрированного модуля управления тормозной системой сначала необходимо обесточить систему и удалить воздух из тормозного контура, затем требуется обновление программного обеспечения IBCU, запись состояния заправки, выход из режима сборки, запись конфигурации модели автомобиля, конфигурации колес, после чего выполнить калибровку датчика хода TMC (эта шаги калибровки датчика хода требуется только для интегрированного модуля тормозной системы с номером детали 3505200-FQ03), в завершение выполнить прокачку в рамках ремонта сухих деталей с помощью диагностического прибора (удаление воздуха внутри IBCU), повторный выход из режима сборки, а также очистку и чтение кодов неисправностей;

  5. После замены датчиков частоты вращения колес также необходимо выполнить адаптивную конфигурацию датчиков частоты вращения колес.

Инструменты : диагностический прибор.
