Замена узла внутренней панели стойки A

  1. Снять оригинальную деталь:

    Предупреждение

    Меры предосторожности =＞ см. Ремонтные работы кузова — Защита автомобиля / Меры безопасности.

    Внимание

    • Измерить размеры геометрии кузова для правки, проверить соединительные элементы на предмет Деформация;

    • Использовать измерительные инструменты, такие как телескопическая измерительная линейка.

    Снять оригинальную деталь:

    1. Демонтировать внешнюю панель боковины;

    2. Очистить зону сварки до обнажения сварочных точек;

    3. Высверлить сварочные точки ①, относящиеся к узлу внешней монтажной панели крыла;

    4. С помощью зубила и молотка разъединить сварные точки, демонтировать узел внешней монтажной панели крыла ②;

    5. Очистить зону сварки до обнажения сварочных точек;

    6. С помощью пневматической дрели высверлить сварные точки ①, относящиеся к передней соединительной пластине боковины, как показано на рисунке;

    7. С помощью зубила и молотка разъединить сварные точки, демонтировать переднюю соединительную пластину боковины ②;

    8. С помощью ключа демонтировать точку болтового соединения ①, показанную на рисунке;

    9. С помощью пневматической дрели высверлить сварные точки ①, относящиеся к переднему усилителю боковины, как показано на рисунке;

    10. С помощью зубила и молотка разъединить сварные точки, с помощью отрезного станка выбрать подходящее положение для резки переднего усилителя боковины и демонтировать передний усилитель боковины ②;

    11. Очистить зону сварки до обнажения сварочных точек;

    12. С помощью пневматической дрели высверлить сварные точки ① в зоне, показанной на рисунке;

    13. С помощью ключа демонтировать точку болтового соединения ②, показанную на рисунке;

    14. С помощью зубила и молотка разъединить сварные точки и демонтировать узел средней внутренней панели стойки A ③.

  2. Подготовка новой детали:

    1. Удалить антикоррозионное покрытие вокруг внутренних и внешних кромок новой детали;

    2. Нанести антикоррозионный слой на обрезанные кромки, нанести грунтовочный состав для сварки в местах сварки новой детали;

    3. Очистить зону работ от сварочного грата, удалить антикоррозионное покрытие в зоне соединения кузова;

    4. С помощью самофиксирующихся зажимов зафиксировать передний усилитель боковины (новую деталь) и сварной узел средней внутренней панели стойки A на кузове;

    5. Отрегулировать установочное положение;

    6. Нанести грунтовочный состав для сварки в зоне соединения;

  3. Сварка:

    1. Зафиксировать узел средней внутренней панели стойки A на кузове с помощью самофиксирующихся зажимов;

    2. Выполнить соединение с помощью точечной сварки;

    3. Выполнить антикоррозийную обработку в новой зоне сварки;

    4. Загерметизировать герметиком стыки между компонентом и кузовом;

    5. Установить передний усилитель боковины ① на автомобиль с помощью самозажимных фиксаторов;

    6. Выполнить сварку с помощью оборудования для точечной сварки и сварки MIG в соответствии с точками сварки ①;

    7. Установить узел внешней монтажной панели крыла ② на автомобиль с помощью самозажимных фиксаторов;

    8. Выполнить сварку с помощью оборудования для точечной сварки и сварки MIG в соответствии с точками сварки ①;

    9. Удалить остатки сварочных точек;

    10. Выполнить антикоррозийную обработку в новой зоне сварки;

    11. Загерметизировать герметиком стыки между компонентом и кузовом;

    12. Нанести финишную эмаль на внешнюю поверхность.
